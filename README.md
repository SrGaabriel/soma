# ➕ soma

A pure functional programming language with strong static type inference and type classes made with performance in mind.

Current features:

- [x] Basic data types
- [x] Basic arithmetic operations
- [x] Functions
- [x] Constant bindings
- [x] Structs
- [x] Polymorphism
- [x] Function currying
- [x] `do` blocks
- [x] `let .. in` expressions
- [x] Pretty error logging
- [x] Strong & static type inference (Hindley-Milner)
- [x] Lambdas
- [x] Type classes (not instantiable yet)
- [x] Multiline Strings
- [x] Arrays
- ... more!

> To see some examples, check the `examples` folder!
