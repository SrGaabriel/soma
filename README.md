# ➕ soma

A prototype programming language to learn Haskell and delve deeper into functional programming & FP language design 

Current features:

- [x] Functions
- [x] Constant bindings
- [x] Structs
- [x] Polymorphism
- [x] Function currying
- [x] `do` blocks
- [x] `let .. in` expressions
- ... more!

> To see some examples, check `app.soma`!
